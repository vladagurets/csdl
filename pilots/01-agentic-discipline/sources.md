# Pilot 01 — Primary Source Anchors

Content freeze: 2026-07-17.

## Superpowers

Primary source: official `obra/superpowers` repository README.

Claims permitted in Pilot 01:

- Superpowers is an agentic skills framework and software-development methodology.
- Its documented workflow moves through brainstorming, implementation planning, TDD, review, and completion workflows.
- Relevant skills activate as mandatory process guidance rather than optional decoration.

## Compound Engineering

Primary source: official `EveryInc/compound-engineering-plugin` repository README.

Claims permitted in Pilot 01:

- Compound Engineering aims to make each unit of engineering work make later units easier.
- Its core loop is brainstorm → plan → work → review → compound.
- The compound step codifies reusable learning so the next cycle starts with better context.

## Editorial framing

The comparison is complementary, not adversarial:

- Superpowers is framed as process enforcement for the current task.
- Compound Engineering is framed as retained learning and leverage across tasks.
- Both include planning and review; the card must not imply exclusive ownership of either practice.
