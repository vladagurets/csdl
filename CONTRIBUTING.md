# Contributing to CSDL

CSDL is publicly developed but currently maintains a single copyright owner.

Issue reports, factual corrections, and discussion are welcome. Do not submit
code, documentation, visual assets, or other copyrightable material unless the
maintainer has requested it and a written copyright assignment has been agreed
before submission.

Unsolicited pull requests will not be merged. Opening a pull request does not
transfer copyright ownership, and the repository license is not a substitute
for a copyright assignment.

Before any approved contribution:

1. read `AGENTS.md`, `DECISIONS.md`, `STATUS.md`, and `LICENSE`;
2. agree the exact scope with the maintainer;
3. complete the requested written copyright assignment;
4. preserve canonical copy, accepted raster evidence, public vocabulary, and
   version boundaries;
5. include the validation evidence required by `AGENTS.md`.

Feedback or a contribution proposal may be opened as a GitHub issue. Commercial
licensing requests should be directed through <https://github.com/vladagurets>.
