# CSDL Arsenal Expansion v0.1

This directory is an evidence-gated incubation package for the user-approved
extension of the CSDL arsenal. It does not mutate Component Library v0.1,
Recipe Library v0.5, Prompt DSL v0.5, Analytical Mode v0.1, Accessibility
v0.1, Design Book v1.0, or any accepted raster byte.

The package proposes eight recipes, three reusable components, five relations,
three orthogonal expression modes, two candidate rendering profiles, and six
analytical families. Public promotion targets are Component Library v0.2,
Recipe Library v0.6, and Analytical Mode v0.2.

## State

- Machine contracts and deterministic analytical proofs: candidate.
- Recipe raster candidates: generated in three independent variants per recipe.
- Package-local selection: complete; the user selected `v1` for recipes
  `024-031`, and the selected files are byte-identical to their recalibrated
  sources.
- Public promotion: not executed. Component Library v0.1, Recipe Library v0.5,
  Analytical Mode v0.1, and Prompt DSL v0.5 remain canonical until a separate
  promotion objective approves the candidate vocabulary and versioned targets.
- Existing sixty-file accepted raster inventory: immutable dependency.

```bash
.venv/bin/python tools/build_arsenal_expansion.py extensions/arsenal-expansion-v0.1
.venv/bin/python tools/validate_arsenal_expansion.py extensions/arsenal-expansion-v0.1
```
