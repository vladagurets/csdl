# Threshold

## Meaning

`Threshold` is a condition or boundary whose crossing changes state or
interpretation. Unlike `Divider`, it is not a neutral separation. Unlike
`Axis`, it does not own the full domain.

## Uses

State transitions, acceptance criteria, target boundaries, phase gates, and
explicit tolerance crossings.

## Exclusions

Decorative rules, unlabeled color changes, generic section separators, and a
renamed `Node(role=gate)` without an explicit crossing condition.
