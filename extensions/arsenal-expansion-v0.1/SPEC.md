# CSDL Arsenal Expansion v0.1

## Purpose

Expand the explanatory range of CSDL only where the existing twenty-three
recipes, fifteen components, three expression levels, and ten analytical
families leave a distinct semantic gap.

## Version boundary

This is a candidate extension, not an in-place edit. Baseline contracts remain
canonical until every promotion gate passes. New recipe packages may use the
candidate vocabulary inside this directory only.

## Acceptance contract

1. Each recipe owns a problem not already owned by its nearest baseline recipe.
2. Each component is reusable across at least two recipe or analytical needs.
3. A/B/C continue to control amplitude; mode controls whether text, relations,
   or data own the composition.
4. Analytical proofs use typed synthetic fixed data and deterministic derivation.
5. Every recipe receives three independent 1920x1080 candidates before selection.
6. Existing accepted raster hashes remain byte-identical.

## Promotion target

- Component Library v0.2: eighteen public components.
- Recipe Library v0.6: thirty-one evidence-backed recipes.
- Analytical Mode v0.2: sixteen analytical families.
- Prompt DSL v0.6 only if candidate components or relations cross the public gate.

## Non-goals

- No quota toward fifty recipes.
- No decorative style family.
- No new Level D or Level E.
- No UI-shell vocabulary.
- No automatic visual promotion before the user selection gate.
